# LeetCode_JS

AI 赛道内容助手（小红书场景）。

## 模块

- **博主分析（Tab1）**
  - 展示 AI 赛道 Top30 博主头像与名称。
  - 点击博主可查看：个人特点、内容特点、受欢迎原因。
  - 展示该博主最受欢迎 5 篇帖子和最近发布 5 篇帖子。

- **选题分析（Tab2）**
  - 顶部展示当日 AI 赛道热门话题。
  - 用户可输入选题方向/灵感，结合目标受众进行分析。
  - 返回风险提示、推荐选题与内容结构建议。

## 启动

```bash
npm start
```

访问：`http://localhost:3000`

## 检查

```bash
npm run check
```
